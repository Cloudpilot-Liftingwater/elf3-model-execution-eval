## 性能和内存

5秒工作站socket测试：反馈观察发送开销P50 59.651μs，P95 101.801μs，P99 131.987μs，最大262.586μs；无记录器P50 0.629μs，20,000次调用的payload工厂调用次数0。5,500条29维合成事件gzip文件176,996字节。固定姿态容易压缩，这个文件体积不可外推真实运动数据；31维功能另由测试验证。

上述是Linux工作站的Python实现测量，不是机器人实时保证，也没有测ROS中间件回调耗时。记录器队列有界4096项；过载丢样不阻塞控制。

120秒全量分析实测约19.62秒，峰值RSS 785,732 KiB（约767MiB），无swap。分析当前按时钟段加载数据，包含全分辨率对齐和滞后搜索；尚不是无限时长流式统计器。建议首轮按15–120秒采集。这个限制不影响记录端的有界内存。

## 复现

先按README安装，在本项目根目录：

```bash
python -m unittest discover -s tests -v
python tools/validate_host_patch.py /path/to/matching/src/bxi_example_py_elf3 --output /path/to/new-patch-check.json
python tools/validate_normal_onnx.py /path/to/model_normal.onnx --output /path/to/new-normal-validation
python tools/benchmark_observer.py --output /path/to/new-benchmark --seconds 5
```

后两个工具只读模型或发送本机合成数据，不连接机器人。ONNX验证需要可选依赖 `pip install '.[validation]'`。socket测试需要本机AF_UNIX权限；本次默认沙箱拒绝bind，获准本机离线测试后39项全部通过，真实运行记录保存在tests.log。

历史原始数据只读保留在：

- `/data/tmp/sonic_tracking_review.V3y4Ti/run.O6cEXF/events.jsonl`
- `/data/tmp/sonic_tracking_review.164vj5/run.DICc1i/events.jsonl`

按README依次import/analyze即可重做。原始文件SHA256、源录制metadata、每段阈值、计数和过滤原因均写入报告JSON。输出索引不是原始记录替代品，不应删除原文件。
